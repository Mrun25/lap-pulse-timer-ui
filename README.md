# Lap Pulse Timer

A lap timer for racing tracks. Pick a track from the list, open its page and time your laps. Track data lives in `src/data/tracks.ts`. Frontend-only project, no backend.

## Stack

Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run lint    # eslint
```
